# AI Football Live - 3D Model Files

Upload these files to this folder:

- `female-player.glb` — rigged adult female football player. The same model is loaded twice and team clothing is recolored at runtime.
- `goalkeeper.glb` — rigged goalkeeper model.

For the best result, keep animation clips embedded in each GLB.

Recommended player clip names (the loader also recognizes similar names):
- Idle
- Run / Jog / Sprint
- Kick / Shoot / Soccer
- Celebrate / Victory / Cheer

Recommended goalkeeper clip names:
- Idle
- Save Left / Dive Left
- Save Right / Dive Right
- Miss / Defeat / Fall

The game falls back to the existing simple 3D characters if these files are missing, so uploading models will not break the live game.
